## The SPED Workflow: What Actually Matters

Writing a compliant IEP isn't one task. It's a **workflow** of 6 stages, each with different data and different compliance requirements:

1. **Intake** — Gather present levels (PLOP), assessment data, parent input, observation notes
2. **Goal Writing** — Convert data into measurable annual goals with clear baselines
3. **Service Planning** — Determine special education services, accommodations, related services
4. **Compliance Check** — Ensure IDEA, state, and district requirements are met
5. **Parent Communication** — Write accessible summaries for IEP meetings
6. **Progress Monitoring** — Set up data collection that actually works with your time

Most AI tools handle ONE of these poorly. What if there was a tool that handled ALL of them — workflow-style, from intake to progress monitoring?

## A Free Sample: 10 Prompts You Can Use Right Now

You don't have to buy anything to try AI for IEP writing. Here are **10 prompts** that cover the core sections of an IEP:

### 1. PLOP Drafting
```
Draft a Present Levels of Academic Achievement and Functional Performance (PLOP) section for a {grade}-year-old student with {disability_type}. Assessment data: {assessment_summary}. Current academic level: {current_level}. Behavioral observations: {behavioral_notes}. Include strengths, preferences, interests, and concerns (SPIC) from parent input: {parent_input}.
```

### 2. SMART Goal Writing
```
Create 3 measurable annual goals for a {grade}-year-old student with {disability_type} who is currently performing at {current_level}. Baseline data: {baseline_data}. Each goal must include: clear target behavior, conditions, measurable criteria, and a timeframe. Ensure goals address {priority_area}.
```

### 3. SDI Specification
```
Based on the following IEP components, specify appropriate Specialized Instruction and Related Services (SDI): {student_profile}. Student needs: {needs_assessment}. Recommended services from evaluation: {eval_recommendations}. Match each need to specific SDI approaches that are evidence-based for this disability category.
```

### 4. Accommodations & Modifications
```
Generate a comprehensive list of accommodations and modifications for a {grade}-year-old student with {disability_type} who struggles with {specific_challenge}. Consider: {academic_area}, {behavioral_area}, {communication_needs}. Include classroom, testing, and homework accommodations.
```

### 5. Transition Planning (Age 16+)
```
Create a transition plan for a {age}-year-old student with {disability_type} preparing for life after high school. Post-secondary goals: {post_secondary_goals}. Current transition assessments: {transition_assessment}. Include: training/education, employment, and independent living goals (if applicable) with specific transition services.
```

### 6. Progress Monitoring Setup
```
Design a progress monitoring plan for the following IEP goals: {goals}. Data collection should be: {feasibility}. Specify: measurement method, data collection frequency, data recording template, and decision rules for adjusting instruction.
```

### 7. IEP Meeting Summary (Parent-Friendly)
```
Write a parent-friendly summary of this IEP meeting that explains: {key_decisions} in plain language. Avoid jargon. Include: student strengths, identified needs, new services, accommodations, and what parents should do at home to support progress. Tone: respectful, collaborative, empowering.
```

### 8. Compliance Checklist
```
Review the following IEP components for IDEA and {state} compliance: {iep_components}. Check for: required elements present, timeline compliance, service hour accuracy, appropriate disability category, measurable goals, proper signatures, and parent consent documentation.
```

### 9. Parent Communication
```
Draft a professional communication to {parent_name} regarding {topic}. Key points to convey: {key_points}. Tone: collaborative, respectful, clear. Include: next steps, timeline for follow-up, and how parents can participate. This is for a {grade}-year-old student with {disability_type}.
```

### 10. Evaluation Bridge
```
Bridge the gap between this {type} evaluation and the IEP document. Evaluation findings: {eval_findings}. Translate each finding into: specific IEP component it informs, how it affects goal writing, what services it justifies, and what accommodations it requires.
```
