What's Inside (Sample Prompts)

1. PLOP Drafting: "Draft a Present Levels of Performance (PLOP) section for a {grade}-year-old student with {disability_type}. Key data: {assessment_summary}, {current_academic_level}, {behavioral_notes}. Include academic, social, and functional performance data."
2. SMART Goals: "Write 3 measurable annual goals for a student with {disability_type} who is performing at {level} in {subject}. Each goal must have: baseline data, criteria, frequency, and conditions."
3. SDI: "Specify Specialized Instruction and Related Services (SDI) for a student who needs support in {area}. Match each goal to an appropriate service (pull-out, push-in, consult, para support). Include minutes per week."
4. Accommodations: "Generate a comprehensive list of classroom accommodations for a student with {disability_type} struggling in {area}. Include environmental, instructional, and assessment accommodations."
5. Transition Planning: "Draft a post-secondary transition plan for a {age}-year-old student with {disability_type}. Include goals for education/training, employment, and independent living (if appropriate)."
6. Parent Communication: "Write a parent/guardian communication template for an upcoming IEP meeting. Include: purpose of meeting, parent rights, how to prepare, what to expect, and contact information."
